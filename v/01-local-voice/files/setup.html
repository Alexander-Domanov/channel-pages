Setting it up

Four things to get right. Get these and the rest is waiting for a download.

The four things

  1. Python 3.12 or newer. From python.org. Take the installer's default options.
  2. One folder for OmniVoice, another for Qwen3-TTS. Not the same folder. They need different versions of the same shared piece, and together they break each other. The two folders can sit side by side anywhere you like.
  3. The maths part first, then the program. OmniVoice needs its maths part installed before the program itself: 
    pip install torch==2.8.0 torchaudio==2.8.0
pip install omnivoice
    On Windows or Linux with an NVIDIA card, the first line comes from pytorch.org instead — pick your system there and copy what it gives you. Then the second line.
    Qwen3-TTS is one line, in its own folder: 
    pip install -U qwen-tts
  4. Room to download and a steady connection. A few gigabytes of free space. The model files arrive by themselves the first time you run the program, which is the slowest part of the whole job.

If it won't start

  • It says a piece is missing or the wrong version. You're probably in the other program's folder, or both landed in one folder. Make a clean folder, install again there.
  • It swallows the command and prints pages of text. Normal. That's the download. Leave it.
  • It finishes but the voice sounds flat or rushed. Almost always the sample, not the settings. Ten seconds of clean, quiet talking, read at the pace you want — recording your sample.
  • Nothing comes out at all. Nine times out of ten there's no sample file, or the path to it points somewhere empty. Check that one first.
  • Still stuck? Both projects keep their instructions on their own page: OmniVoice, Qwen3-TTS. Search there for the exact line of red text you got.

Both are free to sell with

OmniVoice and Qwen3-TTS are both open source under the Apache 2.0 licence, which allows commercial use. The videos you make with them are yours to upload and monetise. The narrator's voice is a different matter: your own voice is yours, anyone else's needs their written permission.
