Setting it up

Four things to get right. Then you wait for a download.

The four things

  1. Python 3.12 or newer. From python.org. Take the default options.
  2. One folder per program. Not the same folder. They need different versions of the same shared piece, so together they break each other. Anywhere on your disk will do.
  3. The maths part first, then the program. In the OmniVoice folder: 
    pip install torch==2.8.0 torchaudio==2.8.0
pip install omnivoice
    On Windows or Linux with an NVIDIA card, get the first line from pytorch.org instead.
    Qwen3-TTS is one line, in its own folder: 
    pip install -U qwen-tts
  4. Room to download. A few gigabytes of free space and a steady connection. The model files arrive on their own the first time you run the program, and that's the slow part.

If it won't start

  • It says a piece is missing. You're probably in the other program's folder. Make a clean folder and install again.
  • It prints pages of text and seems stuck. That's the download. Leave it.
  • The voice sounds flat or rushed. That's the sample, not the settings. Record ten quiet seconds at the pace you want — recording your sample.
  • Nothing comes out. Nine times out of ten there's no sample file, or the path to it is empty. Check that first.
  • Still stuck? Both projects keep their instructions on their own page. OmniVoice, Qwen3-TTS. Search there for the exact red text you got.
