Setting it up

Four things to get right. Miss the first one and the rest won't matter.

  1. One program, one folder. Both programs need different versions of the same helper, so they can't share a folder. Put each one where the other can't see it. This is the single reason most people give up, and it takes ten seconds to avoid.
  2. Read the license before you download. The download page says whether you're allowed to sell what you make. Both programs on this page allow it. Plenty of free ones don't, and you find that out after you've made twenty videos.
  3. Do the download on Wi-Fi. It's a few gigabytes and takes a few minutes. Start it and go make coffee.
  4. Nothing here needs a fast computer. An eight-gigabyte laptop from 2022 handled it while I kept working in other windows.

If it won't start

  • Both programs stopped working after you installed the second one. That's the folder problem. Move them apart, or delete both and install them one at a time.
  • It says a part is missing. The download didn't finish. Start it again, it usually resumes on its own.
  • It runs but nothing comes out. Check that you actually picked your recorded sample. Without it there's no voice to copy.
  • It's slow. That's normal, it's not stuck. A twenty-minute script takes about twenty minutes, and the first run also has to wake the program up, which adds a minute.
